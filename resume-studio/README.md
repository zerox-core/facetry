# 页间 Folio

以简历原文为中心的面试工作台。此目录是独立的新项目，不修改原 `interview-site` 的前端或数据。

## 启动

需要 Node.js 22 或更新版本。

```powershell
cd D:\project\FaceTry\resume-studio
npm install
npm start
```

打开 http://localhost:3210 。默认仅监听本机 `127.0.0.1`。需要换端口时，在启动前设置 `$env:PORT="3211"`。

## 使用

1. 点击「上传简历」，支持 PDF、DOCX、TXT、PNG、JPG，单文件不超过 20 MB、最多 20 页。
2. 预览后，填写可选岗位并点击「生成面试问题」。原文与必要的页面截图会发送至配置的模型服务，通常需要 1–3 分钟。
3. 问题标记显示在简历对应段落旁。点击数字展开/收起问题；目录可跳转对应经历。对定位不准确的标记，点击「校准位置」，再点击简历上的准确位置。
4. 面试前点击 × 排除题目，被排除的问题可恢复。点击「开始面试」进入逐题 1–5 分评分与备注记录。
5. 点击「结束并评价」，补充整体观察，再生成综合评价。未评分的问题不计入均分；被排除的问题不计入评价。
6. 可导出 Markdown 完整记录，包含评分、备注、参考要点、排除状态与综合评价。

内置「林知远」为虚构示例，独立保存在浏览器本地。示例的评价按钮生成明确标注的记录摘要，不调用模型。真实上传档案和面试记录保存在 `data/`，刷新后继续使用。

## 大模型配置

本次已沿用原项目的配置，复制到此目录的 `config.json`。服务端读取配置，密钥不返回前端，不写日志，文件已加入 `.gitignore`。

新环境可以复制 `config.example.json` 为 `config.json`，填写 `baseUrl`、`apiKey`、`model`。接口遵循 OpenAI-compatible `/chat/completions`，支持 JSON 输出。PDF 会同时提供文字行和页面截图，扫描件/图片解析需要模型支持视觉输入。

提示词位于 `prompts.js`：参考原项目的项目深挖、STAR、技术取舍、追问与评分依据，新增原文行编号/页码定位以及以实际面试证据为基础的综合评价。评价供面试官复核，不自动作录用决定。

## 排版与定位

- PDF：本地 PDF.js 渲染原版，每行提取页码、横纵坐标；模型引用行编号后由服务端绑定真实坐标。
- 扫描件 / 图片：模型根据页面估计位置，标记为估算，支持人工校准。
- Word / TXT：解析为文本并在纸张画布重新排版，不承诺保持 Word 原始布局。
- 不依赖在线字体、图标或样式服务，除模型调用外页面资源均在本地。

## 验证

```powershell
npm test
```

测试覆盖文件校验、模型定位、筛题恢复、评分校验、记录持久化、评价筛选与失效、重复任务和生成期间的记录冲突。测试使用临时独立数据，不修改真实档案。

`node test/make-fixtures.js` 可生成不含真实个人信息的两页 PDF 和中文文本测试简历。浏览器检查应覆盖：上传、跨页标记、展开/关闭、筛题恢复、备注刷新保留、评价生成与窄屏布局。

## 目录

```text
server.js           本机 HTTP 服务、文件与记录存储、异步模型任务
prompts.js          简历出题与综合评价提示词
public/app.js       面试工作台交互
public/style.css    独立视觉与响应式布局
public/demo.js      虚构示例简历
public/vendor/     PDF.js 运行库（沿用原项目的第三方库）
data/              新项目自己的简历和记录
test/              接口测试、虚构测试材料
```

这是单人本机工作台，没有账号与多人权限系统。若要作为团队服务部署，需要另行实现登录、访问控制与加密存储。不要将 `config.json` 或 `data/` 上传到公开仓库。
