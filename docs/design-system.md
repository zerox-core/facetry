# Facetry 设计规范

面试官工作台所有页面统一遵循本规范。新增或修改页面前先读这份文档；**token 的唯一来源是 `src/index.css`**，公共组件位于 `src/views/ui.tsx`。两者和本文档不一致时，以代码为准，并同步更新本文档。

---

## 1. 主题

**关键词：面试官的桌面。** 深色桌面托着暖白纸张，内容像一份份摊开的简历和记录。

- 低饱和墨蓝，整体克制、像办公用品，不追求科技感。
- **禁止：** 渐变和发光、玻璃拟态、全大写标签、衬线字体、emoji、装饰性 AI 元素（星星、光球、闪烁）。
- 虚构演示数据要夸张到一眼能看出是假的（例如「精通 43 门语言」），避免被误当成真实信息。

## 2. 配色

| 角色 | Token / 类 | 值 | 用途 |
|---|---|---|---|
| 墨色（承托层） | `--ink` / `.ws-bar` `.login-desk` | #1d2939 + 6% 白点阵 22px | 顶栏、面试间会话栏、登录桌面 |
| 画布 | `--canvas` / `.ws-canvas` | #f4f3ef | 页面底色 |
| 纸面 | `--paper` / `.ws-paper` | #fffdf9 | 所有内容卡片、简历、题目区 |
| 主色 | `blue-600` | #334d70 | 常规主按钮、已完成状态、进度 |
| 主色 hover | `blue-700` | #283e5c | |
| 强调色 | `amber-400` | Tailwind 默认 | **每屏只能出现一处**：入口 / 下一步 / 当前位置指示 |
| 文字 | `slate-900 / 700 / 500 / 400` | | 标题 / 正文 / 次要 / 辅助 |
| 分隔线 | `slate-100`（卡片内）/ `slate-200`（区块间） | | |

`blue-*` 已在 `@theme` 中整体替换为墨蓝，**不要再引入 sky / indigo 等其他蓝色**。

**语义色**：只用「浅底 + 深字」的形式，不做大面积色块。

| 含义 | 底 | 字 | 圆点 / 高亮 |
|---|---|---|---|
| 亮点、通过、推荐 | `emerald-50` | `emerald-700` | `emerald-500` / #d1fae5 |
| 待核实、风险、待评价 | `amber-50` | `amber-700` | `amber-500` / #fde68a |
| 中性、待定 | `slate-100` | `slate-600` | `slate-300` |
| 录制中 | | | `red-400` + `animate-pulse`（只用于计时器） |

**墨色层上的文字**：主文字 `text-white`，次要 `white/55`，辅助 `white/45`；边框 `white/15`，悬停底色 `white/10`。

## 3. 字体与排版

- 字体：`Inter` + `Noto Sans SC`，通过 `--font-sans` 设置，已在 `index.css` 中接入。
- 所有数字使用 `tabular-nums`（body 已开启 `tnum`）。

| 层级 | 字号 / 字重 | 场景 |
|---|---|---|
| 展示 | 40px / 600 | 仅登录页主标题 |
| 页标题 H1 | `text-2xl` 24px / 600 | 每页顶部，每页一个 |
| 题目标题 | 22px / 600，行高 1.5 | 面试间题干、评价页 |
| 区块标题 H2 | `text-lg` 18px / 600 | 通过 `SectionHead` 渲染 |
| 大数字 | 28px / 600 | 统计卡 |
| 正文 | 15px（重要）/ 14px（默认）/ 400 | |
| 次要 | `text-sm` 14px，`slate-500` | 副标题、说明 |
| 辅助 | `text-xs` 12px，`slate-400/500` | 标签、元信息 |
| 最小 | 11px | 仅用于徽标、步骤编号 |

标签文字用正常大小写和中文，不加字母间距。

## 4. 尺寸与间距

| 项目 | 规范 |
|---|---|
| 页面容器 | `max-w-7xl px-6 py-8` |
| 顶栏高度 | 56px（`h-14`）；面试间会话栏 64px（`h-16`） |
| 区块间距 | `space-y-8`（32px）；标题到内容 `mb-4` |
| 卡片内边距 | `px-5 py-4`（列表行 / 统计卡），`p-5`（表单卡） |
| 阅读宽度 | 简历 640px，题目区 760px |
| 圆角 | 卡片 `rounded-xl` 12px · 按钮和输入框 `rounded-lg` 8px · 标签 `rounded` 4px · 头像和徽标 `rounded-full` · 纸张 2px |
| 控件高度 | 按钮 40px（`h-10`）· 搜索框 36px · 行内小控件 32px · 评分格 24px |
| 栅格 | 基础单位为 4px，只用 Tailwind 刻度，不写奇数像素 |

**层级（阴影）**：静止用 `--shadow-paper`（`.ws-paper`），悬停或抬起用 `--shadow-lift`（`.ws-lift`、浮层菜单），登录纸张使用专用的 `.login-paper`。**卡片不加 border**，阴影中已包含 1px 描边。

## 5. 组件（`src/views/ui.tsx`）

| 组件 | 用法 |
|---|---|
| `Btn variant="solid"` | 墨蓝主按钮，页面上的常规主操作 |
| `Btn variant="accent"` | 琥珀色，**每屏只放一个**，给「现在该做的事」（进入面试间、下一题、提交评价） |
| `Btn variant="ghost"` | 白底加描边，次要操作（返回、上一题） |
| `Card` | 纸面卡片（`ws-paper rounded-xl`），所有内容块的默认容器 |
| `SectionHead` | 区块标题；右侧的 `sub` 放计数或说明 |
| `ScoreStamp` | 5 分制得分。≥4 显示绿色，<3.2 显示琥珀色，其余显示墨色 |
| `Label` | 表单字段标签 |

**常用模式**（尚未抽成组件，按以下类名复用）：
- **标签 Chip**：`rounded px-1.5 py-0.5 text-xs` + 语义色底和字。
- **选项卡**：`after:` 伪元素下划线 `h-0.5 bg-amber-400`，用 `scale-x-0 → 100` 切换（顶栏、题目选项卡）。
- **分段筛选**：灰底容器，内部 `rounded` 按钮，选中态为 `bg-white shadow-sm`。
- **选中的筛选胶囊**：`bg-[#1d2939] text-white`。
- **输入框**：`rounded-lg border-slate-200`，聚焦态为 `border-blue-500 ring-2 ring-blue-100`。
- **「下一场 / 当前」标记**：行左侧放 `w-1 bg-amber-400` 竖条，再配 `amber-100` 标签。
- **浮层菜单**：`rounded-lg bg-white shadow-[var(--shadow-lift)] login-fade`。

## 6. 交互

- **一屏一个焦点**：琥珀色只标记下一步，其余操作使用墨蓝或 ghost。
- 可点击元素一律带 `cursor-pointer`，并有 hover 态（改变颜色或底色，卡片用抬起）。
- 键盘：焦点环为 `outline-2 outline-offset-2 outline-blue-600`；浮层支持 `Esc` 关闭；面试间用数字键 1–5 打分，用 ← → 切题。
- 破坏性操作（重置数据、提交评价时有未评分题）需二次确认：第一次点击给出提示，再次点击才执行。
- 自动保存需给出反馈，文案为「已自动保存 HH:MM」，不弹 toast。
- 需要短暂告知结果时用 toast，2.4 秒后自动消失。
- 演示或自动播放内容：用户一操作就停止自动播放、交还控制权，并提供「重新演示」入口。

## 7. 动效

| Token | 值 | 用于 |
|---|---|---|
| `--dur-fast` | 150ms | 颜色变化、按压 |
| `--dur-base` | 300ms | 位移、展开、选项卡下划线 |
| `--dur-slow` | 700ms | 进度条、描线、分数条 |
| `--ease-out` | cubic-bezier(.2,.7,.2,1) | 所有动效共用 |

| 类 | 效果 |
|---|---|
| `.ws-rise` | 入场：上移 8px 并淡入。通过 `--i` 或 `[--i:n]` 设置顺序，每级延迟 60ms。页面内的区块按 0、1、2、3 顺序排列 |
| `.ws-grow` | 宽度从 0 开始增长（进度或分数条） |
| `.ws-lift` | 悬停时上移 2px，阴影切到 `--shadow-lift` |
| `.ws-press` | 按下时 `scale(.98)`，`Btn` 已内置 |
| `.login-fade` | 浮层或新出现内容的轻量淡入（0.4s） |
| `.login-draw` | 连接线描出 |

规则：
- 切换页面时 `main` 以 `key={view}` 重新挂载，使入场动画重新播放；面试间切换题目时同理（`key={idx}`）。
- 只动 `transform`、`opacity`、`width`、颜色，不动布局属性。
- `prefers-reduced-motion` 开启时关闭位移和入场动画，只保留颜色过渡。新增动效必须加入该媒体查询。

## 8. 新页面清单

1. 根节点处于 `ws-canvas` 之内；使用页面容器和一个 H1 页标题。
2. 内容块用 `Card` 或 `ws-paper`，不写 `border bg-white`。
3. 各区块加 `ws-rise`，并按顺序设置 `--i`。
4. 确认本屏唯一的琥珀色焦点；其余按钮使用 solid 或 ghost。
5. 状态颜色只用第 2 节中的语义色。
6. 数字使用 tabular-nums；不出现全大写、衬线字体和渐变。
7. 在 lg 以下能正常堆叠（多栏改为单栏，表格可横向滚动）。

## 9. 面试间与实时会话

- **分享面试间**：面试官顶栏的「分享面试间」生成 `?join=候选人id` 链接，候选人端（`Join.tsx`）只展示题干与会话，不展示任何分析或评分。未分享时，计时和面试官语音照常记录，但不采集候选人发言。
- **会话记录**：语音转写、文字、文件和图片统一为 `Talk`，存入 `rooms[cid].talk`。只作为补充材料，不参与评分，导出时作为附录。
- **组件**（`src/views/live.tsx`）：`VoiceBars` 是随音量起伏的音量条，`Speaker` 在说话时显示 `voice-ring` 声波，另有 `TalkList` 和 `Composer`。说话状态统一用 emerald。
- **窗口形态**：窗口、全屏（Fullscreen API）、最小化三种。最小化时只保留顶栏并加 `ws-breathe` 底边呼吸，内容区隐藏，但计时和录音不中断。
- **结果分析**（`Result.tsx`）：每场结束提交后进入，也可以从工作台「近期评价」点进来。只有最低的弱项用琥珀色标出。
- 实时通道目前走 BroadcastChannel（同浏览器多窗口），正式版替换为 WebRTC。

## 10. 导航与返回

- 顶部导航（工作台 / 总览 / 候选人 / 题库）是**入口**：点击后清空来源记录，导航高亮始终跟随入口，而不是跟随当前页。
- 页内跳转用 `go(view, cid)`，会记住来源；返回统一用 `go('back')`，按钮文案写成 `← {go.from}`，不要写死目标页。
- 不该回退到的中间状态（例如提交评价后跳到结果分析）用 `go(v, cid, { replace: true })`。
