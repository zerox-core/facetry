# 简历初筛工具

本地运行的简历初筛 Web 应用（Flask 后端 + 浏览器前端），通过 Chrome 调试协议(CDP)接管用户**已登录**的招聘网站浏览器，自动批量初筛简历。

## ⚠️ 重要前提（合规与权限）
- 只在**用户自己已登录的招聘账号浏览器**里代替人工做"翻页/阅读/点击"，不破解平台、不绕过接口、不获取账号密码（业界称 RPA）。
- `config.json` 的 `llm.api_key` 需用户**自己**到 minimaxi.com 注册获取并填入；若没有，把 `llm.enabled` 改为 `false` 即用纯本地关键词规则版（无需联网、零成本）。
- Chrome 调试端口(9222)是**本地端口，切勿暴露到公网**（谁连上等于拿到你的浏览器）。
- 简历含个人信息，仅限 HR 内部使用，不外发。

## 启动方式（技能目录即项目根）
目录含 `app/`、`config.json`、`启动全部.bat`(Windows)、`scripts/start.py`(跨平台)。

- **Windows（推荐）**：运行 `启动全部.bat` —— 自动检测 Python/Chrome、装依赖、起后端(7788)与调试Chrome(9222)、开工具页。若双击无反应，用 Win+R 打开 cmd，粘贴 `cmd /c "技能目录\启动全部.bat"` 回车。
- **跨平台 / 命令行**：`python scripts/start.py`（自动检测 Chrome 并启动）。

## 使用流程
1. 启动后，在弹出的**调试 Chrome** 里登录 lpt.liepin.com 或 ehire.51job.com（仅首次/登录态丢失时需登录）。
2. 打开 http://127.0.0.1:7788/ ，点对应平台「扫描新简历」。
3. 工具按 `职位JD汇总.xlsx` 匹配 → AI/规则打分 → 看板展示判定与理由。
4. 默认 `dry_run=true`（仅模拟，不真点按钮），确认后可在页面取消"仅模拟"再真实操作。

## 目录与自维护
- `app/` 源码；`config.json` 配置；`职位JD汇总.xlsx` 岗位JD；`requirements.txt` 依赖。
- 增改岗位：直接在 `职位JD汇总.xlsx` 的「JD汇总」表加行；某岗位要"硬淘汰"就在备注列写 `没有X经验的不考虑`。
- 依赖页面结构，招聘网站大改版时需相应维护；长时间无响应可点工具页「诊断」看真实 DOM。

## 已知限制（本版为初版，未含后续翻页增强）
- 单页约 20 份（受招聘网站每页渲染限制）；如需突破可联系原作者获取翻页增强版。
