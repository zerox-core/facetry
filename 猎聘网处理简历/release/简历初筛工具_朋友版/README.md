# 简历初筛工具（朋友版）

一套本地运行的简历自动初筛看板。接管你已登录的招聘账号浏览器，按岗位要求自动阅读每份投递简历、打分并给出"通过/不合适"建议，结果汇总到网页看板。

## 它能做什么
- 自动扫描**猎聘网 / 前程无忧(51job)** 的"未处理"简历
- 按 `职位JD汇总.xlsx` 的岗位要求做匹配（AI 语义评估 或 本地关键词规则）
- 网页看板展示每人分数、命中/缺失项、判定理由、原始简历链接
- 可一键（确认后）在招聘页面点"通过筛选 / 不合适"

---

## 一、环境准备（一次性）
1. **Python 3.10+**：https://www.python.org/downloads/  —— 安装时务必勾选 **"Add Python to PATH"**
2. **Google Chrome**：https://www.google.com/chrome/
3. （可选，AI 评估用）到 https://www.minimaxi.com/ 注册，拿到 API Key

## 二、配置
打开 `config.json`：
- 有 MiniMax Key → 把 `llm.api_key` 填成你的 key，`llm.enabled` 保持 `true`
- 暂时没有 → `llm.enabled` 改为 `false`（纯本地规则版，精度略低但零成本零联网）

岗位在 `职位JD汇总.xlsx` 的「JD汇总」表里自行增改；某岗位要"硬淘汰"就在备注列写 `没有X经验的不考虑`。

## 三、启动（两种方式任选）
- **Windows 最省事**：双击 `启动全部.bat`（自动装依赖、起后端 7788、起调试 Chrome 9222、开工具页）。若双击没反应，按 **Win+R** → 输入 cmd → 粘贴 `cmd /c "本目录\启动全部.bat"` 回车。
- **命令行 / 跨平台**：`python scripts/start.py`

> 注意：`.bat` 与脚本用相对路径，请放在工具目录内运行，不要单独移动文件。

## 四、使用
1. 启动后弹出的**调试 Chrome** 里登录猎聘 / 51job（仅首次需登录）。
2. 浏览器打开 http://127.0.0.1:7788/ ，点「扫描新简历」。
3. 看板实时显示进度与判定；默认"仅模拟"（不真点按钮），确认后取消"仅模拟"再真实操作。

## 五、安全与合规（务必读）
- 这是 **RPA（机器人流程自动化）**，只在你**自己已登录**的浏览器里代替人工操作，不破解平台、不获取账号密码。
- **Chrome 调试端口 9222 是本地端口，切勿暴露到公网**（谁连上等于拿到你的浏览器）。
- 简历含个人信息，仅限 HR 内部使用，不外发。
- AI 评估会把简历文本发给 MiniMax 接口推理；介意则用 `llm.enabled=false` 本地规则版。

## 六、已知限制
- 本版为**初版，单页约 20 份**（招聘网站每页渲染限制），非翻页增强版。
- 解析依赖页面结构，招聘网站改版时需相应维护。
- 若扫描长时间无响应，点工具页「诊断」按钮看真实 DOM 再判断。
